## How do I copy all the text from a PDF?

Drop the PDF, wait for the progress bar, then press Copy text. Selecting in a PDF viewer often stops at page boundaries; here every page goes into one preview, so a single copy grabs the whole document.

## Why does my PDF have no text?

Scanned PDFs contain pictures of words, not words. If every page comes back nearly empty, the tool says the PDF looks scanned and links to [OCR PDF](/ocr-pdf). When only some pages are empty, such as a scanned signature page, the note lists them.

## What does the extracted text look like?

| In the PDF | In the .txt file |
| --- | --- |
| Paragraphs | Paragraphs separated by a blank line |
| Headings | Their own line |
| Tables | One row per line, columns separated by tabs |
| Two-column layouts | Usually column by column, sometimes mixed |
| Images, charts, scans | Nothing; use OCR PDF |

Tabs between table columns mean you can paste rows straight into Excel or Google Sheets. Empty cells don't get their own tab, so check that the numbers line up.

## When people convert PDF to text

### Quoting a contract clause in an email

Copy the exact wording of a notice period or payment term instead of retyping it, so the quote matches the signed document word for word.

### Pasting bank statement rows into a spreadsheet

Extract the statement, copy the transaction lines and paste them into a sheet: each row lands on its own line and the columns split at the tabs.

### Feeding a report into a translator or word counter

Translators and word counters want plain text; the preview shows the word count too.

## Troubleshooting

| Problem | Fix | Why it happens |
| --- | --- | --- |
| "This PDF looks scanned" | Run it through OCR PDF. | The pages are images with no text layer. |
| Words are run together or split | Try PDF to Word, or OCR PDF for a clean text layer. | The PDF stores letters with unusual spacing. |
| Columns are mixed up | Copy one column at a time from a PDF viewer. | The PDF stores text in drawing order, not reading order. |
| Strange symbols instead of letters | Use OCR PDF. | The font has no mapping from glyphs to letters. |
| "This PDF is password-protected" | Remove the open password first. | It can't be read without that password. |
