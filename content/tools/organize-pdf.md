## How do I rearrange pages in a PDF?

Every page appears as a thumbnail in reading order. With a mouse, drag a page and drop it on the spot where it should go; the target gets a red outline. With a finger, press the grip in the page's top-left corner and drag, or tap the left and right arrows under the page to move it one place at a time. The big number under each page is its new position and the small "p." number is where it was in the original, so you can check the order at a glance before you save.

Saving copies the pages into a new PDF in the new order. Nothing is re-compressed, so text stays selectable and photos keep their quality.

## How do I rotate just one page in a PDF?

Tap the rotate button on that page. Each tap turns it 90° clockwise, and a small "+90°" label shows how far you've turned it. The rotation is added to whatever rotation the page already had, so a page that was stored sideways ends up the right way up instead of being reset. To turn every page in one go, press Rotate all, or use [Rotate PDF](/rotate-pdf) when that's the only change you need.

## How do I add a blank page or pages from another PDF?

Add blank page puts an empty page at the end of the grid; drag it to where it belongs. It takes the size and orientation of the page just before it, so it matches the document. Add another PDF puts all of that file's pages at the end, with their own thumbnails, ready to be moved between the original pages. You can add several files.

## Can I organize PDF pages on iPhone or Android?

Yes, in Safari or Chrome. The grid shows two pages per row on a phone, and the buttons on each page are 40 pixels square so they are easy to tap. HTML5 drag-and-drop doesn't work on iPhones, so this page uses its own touch dragging on the grip, and the arrow buttons always work as a fallback. Very large files can run out of memory on older phones; split them first with [Split PDF](/split-pdf).

## When people organize PDFs

### Fixing a scan that came out of order or upside down

Sheet feeders jam, pages get re-fed, and a few come out upside down. Drag the strays back into place, rotate the upside-down ones twice, and delete the duplicate that was scanned twice.

### Putting a signed page back into a contract

When a client returns only the signed signature page, add their PDF, drag the signed page into position, and delete the unsigned original so there's one complete copy for your records.

### Building one application packet for a visa or university portal

IRCC and US visa portals, and many university applications, want documents in a set order inside one upload. Add each PDF, arrange the pages to match the checklist, delete blank backs, and save one file. If it's over the upload limit, run it through [Compress PDF](/compress-pdf).

### Adding blank pages for double-sided printing

When printing a booklet double-sided, each chapter should start on a right-hand page. Insert a blank page before any chapter that would otherwise start on the back of a sheet.

### Interleaving front and back scans

If your scanner made one file of front sides and another of back sides, add the second file and move each back page next to its front. For long stacks, merging first with [Merge PDF](/merge-pdf) and then reordering here keeps everything on one grid.

## Troubleshooting

| Problem | Fix | Why it happens |
| --- | --- | --- |
| Dragging scrolls the page on my phone | Drag by the grip in the page's top-left corner, or use the arrows. | Elsewhere on a thumbnail, a swipe scrolls the grid. |
| A thumbnail says "Page 3" instead of a picture | Save anyway and check that page in a PDF viewer. | That page couldn't be drawn as a preview, usually because of an unusual font or image. |
| "Needs a password to open" | Remove the open password first. | Files locked with an open (user) password can't be read without it. |
| The Save button is greyed out | Tap the bin on at least one red page to keep it. | Every page is marked for deletion. |
| A page is still sideways after saving | Rotate it once or twice more and save again. | Some scans store pages with an unusual starting rotation. |
| The browser tab reloads on a phone | Split the file first or use a laptop. | Phone browsers give each tab limited memory. |
