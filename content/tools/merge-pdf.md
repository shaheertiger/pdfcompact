## How do I combine PDF files without Adobe Acrobat?

You don't need Acrobat or any installed software. This page does the same job in the browser you're using right now: it reads each PDF, copies its pages into a new document and saves the result on your device. Because nothing is sent to a server, it works for private files such as bank statements, medical records and signed contracts.

On Windows and Mac you can also merge in some built-in apps (Preview on a Mac can drag pages between files), but those take more steps and don't work the same way on a phone. This page works the same on Chrome, Edge, Firefox and Safari, on desktop and mobile.

## How do I merge PDFs on iPhone or Android?

Open this page in Safari or Chrome, tap the box and choose your files from Files, Google Drive or Downloads. Reorder by dragging the grip on the left of each file or by tapping the up and down arrows, tap Merge, then save the result. On older phones, keep the total under about 100 MB; very large merges can run out of memory in a mobile browser.

## Can I merge only some pages from each PDF?

Not in one step on this page. Merge copies every page of every file. To use only part of a file, first run it through [Extract PDF Pages](/extract-pdf-pages) or [Delete PDF Pages](/delete-pdf-pages), then merge the trimmed copy. After merging you can fine-tune the order of individual pages in [Organize PDF](/organize-pdf).

## When people merge PDFs

### Job and university applications

Portals often accept a single upload. Combine your CV, cover letter and certificates into one file, in the order the recruiter will read them. If the merged file is over the portal's limit, run it through [Compress PDF](/compress-pdf) afterwards.

### Receipts and expense claims

Scan or photograph each receipt, turn the photos into PDFs with [JPG to PDF](/jpg-to-pdf), then merge them into one claim file. One attachment is easier for finance teams than twelve.

### Contracts and signed pages

When someone returns only the signed signature page, merge it back into the full agreement so there's one complete copy for your records.

### Reports and course packs

Join chapters, appendices or lecture handouts written by different people into one document you can print or share.

### Scanned double-sided documents

If your scanner produced one file of front sides and another of back sides, merging puts them end to end. You can then drag each back side next to its front in [Organize PDF](/organize-pdf).

## Troubleshooting

| Problem | Fix | Why it happens |
| --- | --- | --- |
| A file is marked in red: "couldn't be read" | Open it in a PDF viewer to confirm it isn't damaged, or re-save it with Print to PDF, then add it again. | The file is corrupted or isn't really a PDF. |
| A file is marked in red: "needs a password" | Remove the open password first, then merge. | Files locked with an open (user) password can't be read without it. |
| Pages are in the wrong order | Reorder the files before merging, or fix single pages afterwards in Organize PDF. | The top file in the list becomes the first pages. |
| Merged file is too big to email | Run it through Compress PDF, or split it with Split PDF by Size. | Merging adds file sizes together; it doesn't shrink anything. |
| Form fields stopped working | Flatten each form first with Flatten PDF, then merge. | Fields from different files can clash when combined. |
| Browser tab crashes on a phone | Merge fewer or smaller files at a time, or use a laptop. | Mobile browsers give each tab limited memory. |
