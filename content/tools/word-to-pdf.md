## How do I convert a Word CV to PDF for a job application?

Many job portals (Workday, Greenhouse, Lever, Indeed and most government job sites) ask for a PDF, because it opens the same way for every recruiter. Drop your CV here, pick A4 or US Letter to match the country you're applying in, keep the sans-serif font and convert. Headings, bold job titles, bullet points and a photo come through. Check the result: if your CV relies on a two-column template or text boxes, those are flattened into a single column, and Word's own Save as PDF will keep the design better.

## Does Word to PDF keep tables and images?

Yes. Tables are drawn as a simple grid with borders, column widths fitted to the content, and rows marked as a repeating header in Word shaded grey. Images embedded in the document are placed at their size and scaled down to the page width when they're wider. What isn't kept is the precise look: cell colours, merged rows, image wrapping and floating positions are simplified.

## Why convert here instead of using Word's Save as PDF?

If you have Word on the device in front of you, Save as PDF gives the most faithful result. This page is for when you don't: a phone, a library or school computer, a Chromebook, or a borrowed laptop. It needs nothing installed and nothing uploaded, so it also suits documents you'd rather not send to an online converter.

## When people convert Word documents to PDF

### CVs and cover letters for job portals

Recruiters' systems often accept only PDF, and some reject files over 2–5 MB. Convert here, and if a photo makes the file too big, run it through [Compress PDF](/compress-pdf).

### Assignments for Canvas, Moodle or Blackboard

University portals frequently require PDF so markers see exactly what you submitted. Convert the essay, check the page count and upload it.

### Letters and forms for official applications

Visa, housing and benefit applications often ask for supporting letters as PDF. Convert each one, then join them with [Merge PDF](/merge-pdf) if the form takes a single upload.

### Contracts and agreements to sign

Send a PDF so the other side can't change the wording by accident, then sign it with [Sign PDF](/sign-pdf).

## Troubleshooting

| Problem | Fix | Why it happens |
| --- | --- | --- |
| “Only .docx files are supported” | Save the file as .docx (Word Document) in Word, Google Docs or LibreOffice. | Old .doc and .rtf files use a different format. |
| Layout looks plainer than in Word | Use Word's Save as PDF for designed documents. | Fonts, text boxes, columns and floating images are simplified. |
| “?” replaces some characters | Use Word or Google Docs to export documents in non-Latin scripts. | The standard PDF fonts only cover Latin-script text. |
| An image is missing | Re-insert it as a PNG or JPEG picture in Word and convert again. | EMF and WMF graphics can't be drawn in a browser. |
| Page count differs from Word | Expected; check headings didn't land at a page bottom. | Different fonts and spacing move the page breaks. |
| “Couldn't read this document” | Remove any password protection in Word, save again and retry. | The file is encrypted, damaged or not a real .docx. |
