## Why flatten a PDF form?

- **The form looks different in other viewers.** Each viewer draws fields its own way, so a value can look cut off or vanish on a phone. Flattened, it looks the same everywhere.
- **Locking answers before sending.** Flattening stops a stray click from changing a total or date. It isn't security: someone with an editor can still alter the page.
- **Printing problems.** Some printers skip form fields; flattened values always print.
- **Combining forms.** Two forms with a field named "Name" clash when merged. Flatten each first, then use [Merge PDF](/merge-pdf).

## Flatten form fields or flatten everything?

| | Flatten form fields | Flatten everything |
| --- | --- | --- |
| Filled values | Drawn into the page | Part of the page image |
| Page text selectable and searchable | Yes | No |
| Links | Keep working | Stop working |
| Comments and markups | Optional | Always flattened |
| File size (our test form) | 5 KB → 6 KB | 46 KB at 150 DPI, 87 KB at 220 DPI |
| Use it for | Almost everything | Files that must look identical and never change |

## When people flatten PDFs

### Tax forms and benefit applications

Flatten a completed form before uploading it, so the office sees exactly what you saw.

### Signed contracts and rental applications

Sign a lease or a landlord's rental application with [Sign PDF](/sign-pdf), then flatten it so the landlord gets a fixed copy.

### Annotated drafts

The comments option locks reviewers' highlights and notes into a final copy that prints the same everywhere.

## Troubleshooting

| Problem | Fix | Why it happens |
| --- | --- | --- |
| A value disappeared | Open the original, retype the value, save, then flatten again. | It was never saved into the file, only shown on screen. |
| "Nothing to flatten" | If it still looks editable, use Flatten everything. | Some "forms" are just lines on the page, or were already flattened. |
| Text looks slightly different | Fill and save the form in Acrobat Reader or Preview first. | Fields without a saved appearance get one drawn in Helvetica. |
| File got much bigger | Use Flatten form fields, or run the result through Compress PDF. | Flatten everything stores pages as images. |
| "Needs a password to open" | Remove the open password first, then flatten. | The pages can't be read without it. |
