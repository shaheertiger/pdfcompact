## How do I add text to a PDF?

Choose **Text**, tap the page where the text should start, and type in the box that appears beside the page. Pick the font, size and color there. To move it, drag it; to make it bigger, drag the red corner dot or use the size slider. Press Enter for a new line. The text is saved as real PDF text, so it stays sharp at any zoom and can be searched.

## How do I white out text in a PDF and replace it?

1. Choose **White-out** and drag over the words you want to hide. A white rectangle covers them.
2. Choose **Text**, tap on the white area and type the new words.
3. Match the size: most documents use 10 to 12 pt body text.

This is the quickest fix for a wrong date, a typo in a name or an old address. Remember that white-out is a cover, not a deletion: the original words are still inside the file. For anything confidential, such as an account number, flatten the result afterwards with [Flatten PDF](/flatten-pdf) and **Flatten everything**.

## Can I edit a PDF without Adobe Acrobat?

Yes. Adding text, highlights and drawings doesn't need Acrobat. This page does it in the browser on Windows, Mac, Chromebook, iPhone and Android, without an account and without uploading the file. On a Mac, Preview's markup toolbar can do similar things; on Windows, Edge can add text and ink to PDFs, but neither has white-out.

## When people edit PDFs

### Filling in a form that isn't fillable

Many forms are scanned or exported without fields: rental applications, school forms, medical history sheets. Tap where each answer goes and type it. Add a tick with Pen for checkboxes, then [sign](/sign-pdf) the last page.

### Correcting a typo before sending

Spotted a wrong date or a misspelled name in a PDF you can't regenerate? Cover it with white-out and type the correction in the same font size.

### Marking up a contract or report

Highlight the clauses you want to discuss, draw a box around a figure, and add a short note in red. Send the marked-up copy back to the author.

### Annotating study material

Highlight key lines in lecture notes and past papers, and write answers in the margins with Pen on a tablet.

## Troubleshooting

| Problem | Fix | Why |
| --- | --- | --- |
| I can't move an item, the page draws instead | Tap Select first. | Drawing tools capture every touch on the page. |
| My typed text is tiny | Raise the size slider; 11 to 12 pt matches most documents. | Sizes are in print points, like a word processor. |
| White-out left a visible edge | Drag a slightly larger box. | The cover is exactly the size you draw. |
| Copied text still shows the old words | Flatten the result with Flatten everything. | White-out covers text but doesn't delete it. |

| "This PDF needs a password to open" | Open it with the password, save an unprotected copy, then edit that. | Encrypted pages can't be changed without the password. |
